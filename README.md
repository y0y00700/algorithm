## 문제 풀이

정답 코드는 프로그래머스의 난이도와 문제별로 정리합니다. 같은 문제를 다시 풀면 해당 문제의 풀이를 갱신합니다.

~~~text
프로그래머스/
└── <레벨>/
    └── <문제번호>-<문제명>/
        ├── README.md
        └── <풀이 코드>
~~~

풀이 과정에서 새롭게 알게 된 내용과 개선할 점은 문제 폴더에 함께 기록합니다.
