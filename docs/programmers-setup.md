# 프로그래머스 풀이 자동 저장 연결

이 저장소는 PROGRAMMERS-BADGE-V2 확장 프로그램의 정답 코드 저장 대상으로 사용합니다.

## 한 번만 설정하기

1. 확장 프로그램에서 프로그래머스 문제 또는 프로필 탭을 엽니다.
2. 팝업의 'GitHub 풀이 기록'에서 '저장소 목록 새로고침'을 누릅니다.
3. 저장소 목록에서 y0y00700/algorithm을 선택합니다.
4. '기록 경로'는 비워 두고, 저장소 설정을 저장합니다.
5. 다음 정답 제출 후 이 저장소에 문제 README와 풀이 코드가 생성되는지 확인합니다.

새 저장소가 목록에 없다면, 확장 프로그램이 사용하는 GitHub App의 저장소 접근 설정에 algorithm을 추가한 뒤 목록을 새로고침합니다. 확장 프로그램의 GitHub App과 Codex의 GitHub 연결은 각각 따로 설정합니다.

기존 WebPractice 저장소의 파일은 이 설정을 변경해도 자동으로 옮겨지지 않습니다. 이 저장소 생성 시 기존 파일을 이동하거나 삭제하지 않았습니다.

## 배지와 성장 그래프

- 배지는 확장 프로그램이 동기화한 프로그래머스 계정의 전체 통계를 표시합니다.
- 성장 그래프는 프로필 저장소에서 매일 한국 시간 00:17에 공개 배지 값을 수집해 갱신합니다. 예약 실행은 지연될 수 있습니다.
- 성장 기록은 2026-11-02부터 수집하며, 이전 날짜의 풀이 수는 추정하지 않습니다.
- 그래프를 바로 갱신하려면 프로필 저장소의 Actions → Update Programmers growth → Run workflow를 실행합니다.
- 풀이 코드가 이 저장소에 기록되는 것과 배지 통계 동기화는 별도 기능입니다.
